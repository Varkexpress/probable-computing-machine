# Suggestive scenes off: kc65–kc68

The setting is `META.sug` (kc70); `sugOn()` is true by default. These modules branch at the line or scene with
`sugOn()?on:off`, `...(sugOn()?[[on]]:[[off]])` or `if(!sugOn())return say(off,cb)`. Ids, flags, options and code
paths are unchanged: every option still exists with the same label and sets the same flag, so later beats, threads and
ending lines read the same flags either way.

Scope, as the author clarified it: flirting, teasing, innuendo-flavoured banter and romance stay in both versions. Only
moments that imply sex happened or is about to are replaced: fade-outs and cut-aways, mornings after that imply it, kc66's
"collect" payoff, and the texts and ending lines that refer to it. The off versions keep the kiss, the holding and the
sleeping beside each other, and turn the cut-away into the two of them at rest together.

The replacement text on its own is in `docs/sug_off_text.md`; the per-module reading copies show both versions.

## Tests

`tools/k65_test.js`–`tools/k68_test.js` each have a SUG block that plays every branched scene, morning, thread and ending
line above twice, with `META.sug=1` and `META.sug=0`, and checks that both finish the same way, set the same flags and
produce different text. With `SUGDUMP=<dir>` they write the off-only lines out; `docs/sug_off_text.md` was made from that.
